# Candy Dialogue Creator
**Candy Dialogue Creator by [Candy Arts](https://candy-arts.com) is the free, standalone companion application to [Candy Dialogue Engine](https://github.com/Candy-Arts/Candy-Dialogue-Engine).**

## Features
Candy Dialogue Creator provides a modular GUI for creating and editing dialogues.

![UI_Preview.png](https://candy-arts.com/wp-content/uploads/2026/11/DC-1.2-Screenshot-1.webp)

## Technical Specs
**Available formats:**
- Compiled executables
- Raw Godot project

**Operating System:**
- Linux
- Windows
- MacOS (untested and unsigned)

**Godot:**
- The compiled version is a standalone software and does not depend on Godot.
- The raw project format requires Godot 4.5 and above.

**Hardware:**
- Touchscreens may not be fully compatible at this time.
- Candy Dialogue Creator should work fine on older/low-end hardware.
- A screen resolution of at least 1024×720 is recommended. Higher resolutions will provide a more comfortable experience.
- Multi-monitor setups are supported.

## Instructions
1. Download the compiled executable for your operating system.
2. Unpack and run it.

You will need to create a profile for each Godot project, and provide each profile with the path to its corresponding Godot project, so that Candy Dialogue Creator can import relevant data.

For further information, see the Candy Dialogue Creator [documentation](https://candy-arts.com/index.php/docs/).

## Upgrading
If you are upgrading from 1.1 to 1.2, Candy Dialogue Creator provides tools to convert dialogues, presets and save files to the new format. See the documentation for details.

## Versions
Candy Dialogue Creator 1.2 must be used with Candy Dialogue Engine 1.2.

Candy Dialogue Creator 1.0 and 1.1 are for use with Candy Dialogue Engine 1.0 and 1.1 respectively.
**1.0 and 1.1 are deprecated:** upgrading is recommended if possible, and new Godot projects should use 1.2.

## Themes
Additional UI themes can be downloaded [here](https://github.com/Candy-Arts/Candy-Arts/tree/main/RESOURCES/Candy%20Dialogue%20Creator/Themes)

You also have the option of creating custom themes, or modifying theme through the settings.
